# PDF Lite

GitHub Pagesでそのまま公開できる、ブラウザ完結型のPDFツールです。

## 機能

- PDF結合（順番変更対応）
- PDF分割（1ページずつ／範囲指定）
- PDF圧縮（3段階）
- ページ整理（並べ替え／削除／回転）

PDFの処理はすべて利用者のブラウザ内で行い、サーバーには送信しません。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルとフォルダを、構成を変えずにアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. `Branch` を `main`、フォルダを `/(root)` にして `Save` を押します。

数分後、表示されたURLから利用できます。

## 注意事項

- 初回表示時にPDF処理用ライブラリをCDNから読み込みます。利用時はインターネット接続が必要です。
- パスワード保護されたPDFには対応していません。
- 圧縮機能は各ページをJPEG画像として再構成します。そのため、文字検索・コピー・リンク・フォームは失われます。
- 大容量・大量ページのPDFは、スマートフォンやメモリの少ない端末では処理できない場合があります。

## 使用ライブラリ

- pdf-lib 1.17.1
- PDF.js 3.11.174
- JSZip 3.10.1

各ライブラリは jsDelivr CDN から読み込みます。
